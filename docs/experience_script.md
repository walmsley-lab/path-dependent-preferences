# The Experience Script: a scientific expedition, not a dashboard

*The authoritative storyboard for the public-facing experience (Patrick +
ChatGPT, 2026-08-15). The workbench implements slices of this; the hosted
site realizes it fully. Principle: repeatedly create a mystery, let the
reader make an observation, reveal why it is insufficient, then hand them
the next instrument.*

## The spine

**Observe → Question → Separate → Watch → Probe → Interfere → Formalize →
Create** — the arc from natural history (seeing the phenomenon) through
experimental interrogation (poking it) to the realization that development
itself can be specified and controlled.

## Chapters

1. **A World We Can Know** — open with the artificial society, not the
   transformer. Ten people, threads, places, resources. "We created a
   world. We know every fact in it… and so we can know when the model
   learns the wrong lesson for the right reasons." Click Matthew → person
   first, then the reveal: hidden λ. Reader computes one utility by hand.
2. **Two Ways to Be Right** — the second route quietly illuminates. An
   ordinary example: reader predicts, model answers, 🎉 correct — then the
   reversal: *"we learned almost nothing."* Both routes predicted the same
   answer. The identification problem, discovered rather than lectured.
3. **The Experiment That Separates Them** — "what if we constructed a
   situation where the explanations disagree?" Routes glow blue/orange in
   opposition; the model sits between them; its choice becomes evidence —
   with the restraint stated: behavior matching ≠ mechanism.
4. **Two Childhoods** — pull back: there were two identical newborns all
   along. The curriculum bars. *"Same experiences. Same starting weights.
   Different childhood."* The title finally means something.
5. **Watching a Mind Develop** — the synchronized checkpoint slider, the
   centerpiece. Same question on screen; both organisms age together;
   trajectories accumulate beneath. "Something happened between here and
   here." The reader asks *why* — which earns the descent.
6. **Looking Inside** — six translucent floors, not an activation matrix.
   Probes introduced as answers to "does the model represent Matthew's
   hidden preference anywhere?" Layer overlays; the slider still works —
   internal structure develops before their eyes.
7. **Seeing Is Not Causation** — the second epistemic reversal, mirroring
   chapter 2: decodable ≠ used. The reader has climbed one level and found
   the next limit. They want the next instrument.
8. **Interfering With the Mechanism** — patch, steer, suppress; the
   before-result stays faintly visible behind the after-result. Evidence
   levels enacted, not explained.
9. **What Did It Actually Learn?** — zoom all the way back out: the
   authored graph beside the evidence-coded learned graph (edge styles by
   evidence level: hypothesized / behavioral / representational / causal;
   click an edge → its evidence and provenance). The investigation's
   product IS a graph, completing the circle.
10. **Build a Different World** — the graph becomes editable. The reader
    plants their own spurious route, declares their own equivalence
    constraint, orders their own curriculum, trains their own organism.
    "You have created an identification problem."
11. **Can We Shape Development?** — the post-credits reveal: the system
    measures the organism against the desired graph, proposes
    discriminating experience, retrains. Specify → Develop → Measure →
    Infer → Intervene → Refine. Formal invariants become generated tests;
    violations become curriculum.

## The emotional rhythm

Alternate wonder and doubt: *it works → but that proves less than you think
→ dig deeper → we found the representation → but representation isn't
causation → interfere → it changes → but why did only one organism build it
→ rewind development → order did it → can we do it on purpose?* Technical
depth delivered as discovery, not exposition.

## The persistent object

One graph accompanies the entire journey, changing epistemic role:
**ontology → hypothesis → measurement map → causal model → experiment
specification.** It shrinks to a corner navigator during the descent and
returns for the comparison and the editor. Never a separate feature.

## Design rules

- Every visualization is named by its **question**, not its technique
  ("Where does the model represent the agent's preference?", never "PCA").
- **Evidence meter** persists: ✓/? items that experiments flip — the reader
  always knows why the next screen exists.
- **Every number is clickable** → n, run, checkpoint, commit, examples,
  manifest, reproduce. Provenance as exploration, not bureaucracy.
- **Escape hatch everywhere**: "Go deeper →" opens equations, raw examples,
  methodology, source. Narrative surface + laboratory underneath, neither
  compromising the other.
- **Reader's notebook**: save observations along the way; the tool
  assembles their investigation at the end. They re-perform the reasoning,
  not just read the conclusions.
- **Aesthetic**: laboratory notebook × natural-history exhibit — specimen
  documentation, annotations, restrained type, uncertainty on display.
  Never SaaS-dashboard. Host identity: **Open Pollination** ("Let ideas
  cross. Test what emerges.") — warm-ivory grounds, deep-green serif
  display, vintage-botanical illustration whose below-soil roots form a
  neural network: growth above, learned structure beneath. That motif IS
  the World-graph ↔ learned-structure duality of chapters 1 and 9, and the
  site's "Reveal the system" affordance is our progressive-disclosure
  escape hatch. Site-level framing of this experiment (adopted): *"What if
  training order is part of the architecture?"* Route colors (utility blue /
  cue orange) remain reserved for data encoding within the naturalist
  palette.

## Sequencing (resource-conscious)

Built now (workbench): chapters 1–4 in slice form (world graph, guided
discovery, childhood bars, dev slider + trajectories, evidence meter).
Next: chapter 5 fully (batch checkpoints arriving), 6 (layer tower +
probes). Chapter 8 when Phase B produces its first clean intervention;
9 with Ĝ v1; 10–11 only after the abstractions have carried weight
(laboratory_architecture.md governs). Progression principle throughout:
**increase the complexity of the question before the complexity of the
model** — richer worlds (λ, then (λ,ρ)) before bigger organisms; scale as
external validity, pretrained recruitment as the bridge that matters most.
